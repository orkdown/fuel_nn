# Мониторинг наличия и стоимости топлива на АЗС Нижнего Новгорода

Онлайн веб-сервис для мониторинга цен и физического наличия топлива (**АИ-92, АИ-95, АИ-100/98, Дизель, Газ**) на более чем **120 АЗС** Нижнего Новгорода и агломерации (Бор, Кстово, Дзержинск).

Разработано для персонального использования с адаптацией под:
* **iPhone 17** (iOS Safari, поддержка PWA, Safe Area)
* **Poco X3 Pro** и Android-смартфоны (плавный скролл 120 Гц)
* **ПК и ноутбуки** (двухпанельный режим: карта + каталог)
* Интеграция с **Яндекс.Картами** и **2ГИС** (построение маршрута в 1 клик)

## 🌐 2. Развертывание на VPS (Ubuntu 24.04 LTS)

Сервис полностью настроен под ваш домен **`gdeflex.orkproxy.nx.kg`**.

### Безопасность и изоляция MTProxy:
* **MTProxy (порт 8443)** не затрагивается и работает в штатном режиме.
* Бэкенд слушает локальный порт `127.0.0.1:8080`.
* Веб-сервер **Nginx** принимает внешний трафик на стандартных портах 80 (HTTP) и 443 (HTTPS), перенаправляя пользователя на защищенное соединение без лишних портов в адресной строке (`https://gdeflex.orkproxy.nx.kg`).
* **Certbot** автоматически выпускает и обновляет бесплатный SSL-сертификат Let's Encrypt.

---

### Пошаговая инструкция установки на сервер:

#### Шаг 1. Скопируйте папку проекта на ваш сервер
С вашего компьютера через терминал (PowerShell / Git Bash):
```bash
scp -r C:\Users\orkdown\Desktop\fuel_nn root@ВАШ_IP_СЕРВЕРА:/var/www/
```
*(Либо загрузите архив через FileZilla / WinSCP в `/var/www/fuel_nn`)*

#### Шаг 2. Подключитесь к VPS по SSH и запустите автоустановщик
```bash
ssh root@ВАШ_IP_СЕРВЕРА
cd /var/www/fuel_nn
sudo bash deploy/install_ubuntu.sh
```

Скрипт автоматически:
1. Проверит порты и подтвердит сохранность MTProxy (8443).
2. Установит Nginx, Python3 venv и Certbot.
3. Установит библиотеки и выполнит первую загрузку актуальных цен АЗС.
4. Создаст и включит системную службу `systemd` (`fuel-nn.service`), которая будет автоматически запускаться при перезагрузке сервера.
5. Настроит виртуальный хост Nginx для домена `gdeflex.orkproxy.nx.kg`.
6. Выпустит бесплатный SSL-сертификат Let's Encrypt и настроит авторедирект на HTTPS.

После завершения сайт сразу доступен по адресу:
👉 **https://gdeflex.orkproxy.nx.kg**

## ⚙️ Управление сервисом на сервере

* **Статус службы:** `sudo systemctl status fuel-nn`
* **Перезапуск службы:** `sudo systemctl restart fuel-nn`
* **Просмотр логов в реальном времени:** `sudo journalctl -u fuel-nn -f`
* **Ручное обновление цен на сервере:**
  ```bash
  /var/www/fuel_nn/venv/bin/python -c "from backend.data_manager import manager; manager.update_all()"
  ```
  *(На самом сайте также есть кнопка мгновенного ручного обновления «🔄 Обновить»)*.

├── backend/

│   └── nn_fuel_cache.json     # Локальный кэш цен и координат АЗС

│   └── nginx-site.conf        # Конфиг Nginx с реверс-прокси и Gzip

├── run_local.py               # Локальный запуск
